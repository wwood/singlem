# The 60 bp marker window

SingleM targets conserved sections of single-copy marker genes. A typical window spans 20 amino acids encoded by 60 nucleotides, although insertions and deletions can change the observed nucleotide length.

A read is useful when it covers an entire window. Restricting comparison to the same short region makes sequence novelty measurable even when the source genome is absent from reference collections.

Because these genes ordinarily occur once per genome, their coverage approximates the coverage of the organisms carrying them. Evidence from many independent markers makes the resulting community estimate more robust than any single marker.
